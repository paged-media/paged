Set one property of any object (ADR 132, `Mutation::Set`).

TARGET is one address (ADR 131): `doc`, `rectangle:<id>`, `frame:<id>`, `storyRange:…`, `page:#2`, `layer:<id>`, `swatch:Color/Red`, `style:object/<id>`, `cell:<table>/0,1`, `textVariable:<id>`, … — a selector is not a target (`paged query` lists what one matches). The protocol-70 target object (`{"kind":"layer","layerId":"ua"}`) is accepted, deprecated. PATH is any `propertySchemas` row for the target's kind. VALUE is JSON when it parses (`12`, `true`, `[0,0,100,100]`), a string otherwise (`3mm`, `CenterAlign`), coerced by the path's schema. Prints the value read back.

Usage: paged set [OPTIONS] <DOC> <TARGET> <PATH> <VALUE>

Arguments:
  <DOC>
          IDML or `.paged` document

  <TARGET>
          An address: `doc`, `rectangle:<id>`, `swatch:<id>`, `layer:<id>`, …

  <PATH>
          A `propertySchemas` path for the target's kind

  <VALUE>
          JSON (`12`, `true`, `[0,0,100,100]`) or a plain string (`3mm`)

Options:
  -o, --out <OUT>
          Write the result here. The format follows the extension

      --standard <STANDARD>
          "pdf17" (default) or "pdfx4". X-4 needs a resolvable output intent — give one here or let the document's profile serve
          
          [default: pdf17]

      --output-intent <OUTPUT_INTENT>
          Output-intent profile NAME, resolved against what this run registered. Defaults to the working space

      --output-condition <OUTPUT_CONDITION>
          Human-readable output condition for the OutputIntent dict

      --marks
          Crop marks, registration marks, colour bars, page info

      --pages <FROM-TO>
          0-based inclusive page range, e.g. `0-9`

      --bookmarks
          Write the document's bookmarks as the PDF outline

      --tagged
          Create Tagged PDF: a structure tree of stories and paragraphs, as InDesign's "Create Tagged PDF" writes it

      --fonts <DIR|FILE>
          Font file or directory to make available, repeatable.
          
          A directory is read one level deep and each face is asked for its own family name, so a corpus directory needs no mapping.

      --font-family <NAME[/STYLE]=PATH>
          Bind one family (and optionally a style) to a file, repeatable: `--font-family "Fraunces/Italic=/path/Fraunces-Italic.ttf"`.
          
          Wins over `--fonts` for the same family and style — a scan is a convenience, this is the instrument.

      --font <FILE>
          Fallback face for text no registered family answers for. Absent, the face the CLI bundles (Inter) stands in

      --no-default-font
          No fallback face: text no registered family answers for is not set, and the run says so (to see what a document is missing)

      --cmyk-profile <NAME|FILE>
          CMYK profile: a file path, or a name to resolve against the host's installed profiles (e.g. "Coated FOGRA39").
          
          Absent, the document's own declared profile name is resolved and made the working space. Absent that too, colour is naive math and the run says so.

  -h, --help
          Print help (see a summary with '-h')
