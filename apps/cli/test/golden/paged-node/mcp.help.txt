paged-node mcp

serve the paged MCP tools over stdio, as the engine's Rust `paged mcp` does: a library's documents (store tools), and the engine run here (open_document, run_script, render_page, save_document, create_document, export_document)

options:
  --library <dir>                    the library directory (default: $PAGED_LIBRARY, else ~/.paged/library)
  --plugins <a,b|auto>               load these plugin bundles (package names or paths); `auto` discovers the ones installed in the current directory. A bundle is code that runs with your rights: none loads unless named here or in PAGED_PLUGINS
  --no-plugins                       load no plugin bundles (core objects only; the default, and it overrides PAGED_PLUGINS)
  --debug                            report an unexpected failure with its stack trace (also PAGED_DEBUG=1)
  --font <file.ttf>                  fallback face for text no registered font answers for (default: the bundled Inter)
  --no-default-font                  no fallback face: text no font answers for is not set (to see what a document is missing)
  --cmyk-profile <file.icc>          CMYK working space and PDF/X output intent (an ICC file)
  --engine-from <dir>                resolve the engine (@paged-media/paged) from this directory
  --ml-host <url>                    the local image model host (paged-ml-host; default PAGED_ML_HOST_URL or http://127.0.0.1:7861)
  --text                             human-readable output instead of JSON
  -h, --help                         show help
