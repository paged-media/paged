paged-node <CLI_VERSION> — the paged Node CLI over core and every installed plugin (ADR 324)

usage: paged-node <verb> [args] [options]

verbs:
  get <doc> <address|selector> [path]                                                          read one property, or every property of an object (all matches of a selector); heavy rows (pixels, story text) only with --content
  set <doc> <address|selector> <path> <value>                                                  set one property (value parsed through the path's schema); a selector sets every match in ONE undo step; saves in place unless -o / --no-save
  create <doc> <kind> [props.json|{json}]                                                      create an object of a kind (core: swatch, gradient, colorGroup, style:<family>, textVariable, layer, page, textFrame/rectangle/oval — engine protocol >= 71; or a plugin kind) with its props in ONE undo step, then save
  delete <doc> <address|selector>                                                              delete an object (a selector deletes every match) in ONE undo step, then save
  query <doc> <selector>                                                                       list the addresses a selector matches (kind, [name=…], [label.<key>=…], "page:#1 > frame", plugin kinds)
  schema <doc> [kind|address]                                                                  the property schema of a kind or an object; without one: every kind and typed command
  batch <doc> <ops.json>                                                                       apply a list of ObjectOps ({op:set|create|delete|invoke, …}; invoke a core.<op> command beside them) as ONE undo step, then save
  commands [doc]                                                                               the typed commands (core content / structure ops `core.<op>` and every plugin's) with their argument schemas
  invoke <doc> <commandId> [args.json|{json}]                                                  run one typed command (`paged-node commands` lists them; a core command is ONE undo step and answers created[]: what it made), then save
  run <doc> <script.js> [-- args…]                                                             run a JS module with `paged` = host.objects + typed commands (global, and the default export's argument); saves when it wrote
  ai <doc> <brief> | --new <size> <brief>                                                      Claude (claude-haiku-5-5) writes and runs paged.* scripts until the brief is done; saves when it wrote. Needs ANTHROPIC_API_KEY or `ant auth login`
  export <doc>                                                                                 export through core (pdf, idml, paged) or a plugin exporter (its id or extension); pdf goes through a typed exportPdf command (paged.publish) when one is installed, passing only the options given
  apply <doc>                                                                                  apply data bindings (bindings.json) for one record of --data, then save
  merge <template>                                                                             Data Merge: template + records → merged document(s) in --out, as pdf | idml | paged (through paged.data's typed commands)
  generate <template>                                                                          a batch: one document per record or per group of records (paged.data's planBatch), each a Data Merge of the template, in --out
  preflight <doc>                                                                              the PDF exporter's findings for the document (paged.publish's typed preflight, the editor's Preflight panel); exit 1 when one is an error
  package <doc>                                                                                InDesign's File ▸ Package: the document as IDML with its linked files in Links/, the fonts it sets in, Instructions.txt, a report and the document as .paged (with the module content IDML cannot carry), into a new folder or a .zip
  plugins [doc]                                                                                the discovered bundles, their versions and object kinds
  describe [doc]                                                                               kinds × schemas × typed commands × verbs, as one JSON document (for agents and the docs)
  template fields <doc> | kinds | fill <template> | check <template> <filled> | ingest <doc>   template fields: list them, fill them as a filler (writes .paged, .idml or .pdf), check that a filled document changed only its fields, ingest a document tagged for XML as a template
  ml <health|generate|edit> [prompt]                                                           the local image model (paged-ml-host on this machine, extensions ADR 345): its health, text to image, and an image edited by a prompt (mask, references); nothing leaves the machine
  mcp                                                                                          serve the paged MCP tools over stdio, as the engine's Rust `paged mcp` does: a library's documents (store tools), and the engine run here (open_document, run_script, render_page, save_document)

options (every verb):
  --plugins <a,b>                    load exactly these bundles (package names or paths) instead of discovering them
  --no-plugins                       load no plugin bundles (core objects only)
  --font <file.ttf>                  fallback face for text no registered font answers for (default: the bundled Inter)
  --no-default-font                  no fallback face: text no font answers for is not set (to see what a document is missing)
  --cmyk-profile <file.icc>          CMYK working space and PDF/X output intent (an ICC file)
  --engine-from <dir>                resolve the engine (@paged-media/paged) from this directory
  --ml-host <url>                    the local image model host (paged-ml-host; default PAGED_ML_HOST_URL or http://127.0.0.1:7861)
  --text                             human-readable output instead of JSON
  -h, --help                         show help

Output is JSON; --text (or --format text where --format is not a file format) is for humans.
Exit codes: 0 ok · 1 rejected write or failed check · 2 usage or IO error.
Addresses: doc, page:#1, textFrame:<id>, story:<id>, storyRange:<id>@a..b, swatch:<name>, style:<family>/<name>,
  layer:<id>, plugin:<pluginId>/<kind>/<id>. Selectors: swatch[name=Black], frame[label.<key>=v], page:#1 > frame.
Run `paged-node <verb> --help` for a verb's options.
