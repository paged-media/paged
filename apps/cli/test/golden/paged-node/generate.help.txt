paged-node generate <template>

a batch: one document per record or per group of records (paged.data's planBatch), each a Data Merge of the template, in --out

options:
  --data <x.csv>                     the records (CSV/TSV/JSON/Parquet/XLSX through paged.data)
  --query <sql>                      select the records (default SELECT * FROM "data")
  --out <dir>                        output directory (required)
  --format <pdf|idml|paged>          output format (default paged); pdf through the typed exporter (paged.publish) when installed
  --per <record|group>               one document per record, or per group of records with the same --by values (default record)
  --by <a,b>                         --per group: the fields that make a group
  --records-per-page <single|multiple> Data Merge layout (default single)
  --arrange <rows|columns>           multiple records: fill rows or columns first (default rows)
  --row-spacing <pt>                 multiple records: spacing between rows
  --column-spacing <pt>              multiple records: spacing between columns
  --remove-blank-lines               drop lines whose only content is an empty field
  --image-base <dir>                 where relative image fields resolve (default: the data file's directory)
  --image-field <rectId=@field>      an image placeholder rectangle and its field (repeatable)
  --plugins <a,b>                    load exactly these bundles (package names or paths) instead of discovering them
  --no-plugins                       load no plugin bundles (core objects only)
  --font <file.ttf>                  fallback face for text no registered font answers for (default: the bundled Inter)
  --no-default-font                  no fallback face: text no font answers for is not set (to see what a document is missing)
  --cmyk-profile <file.icc>          CMYK working space and PDF/X output intent (an ICC file)
  --engine-from <dir>                resolve the engine (@paged-media/paged) from this directory
  --ml-host <url>                    the local image model host (paged-ml-host; default PAGED_ML_HOST_URL or http://127.0.0.1:7861)
  --text                             human-readable output instead of JSON
  -h, --help                         show help
