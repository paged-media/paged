paged-node invoke <doc> <commandId> [args.json|{json}]

run one typed command (`paged-node commands` lists them; a core command is ONE undo step and answers created[]: what it made), then save

options:
  -o, --out <file>                   write the result here (format from the extension: .paged, .idml, .pdf)
  --no-save                          apply the change but write nothing (a dry run)
  --result-out <file>                write the bytes the command answers (an exported file) here
  --format <json|text>               output style (default json)
  --plugins <a,b>                    load exactly these bundles (package names or paths) instead of discovering them
  --no-plugins                       load no plugin bundles (core objects only)
  --font <file.ttf>                  fallback face for text no registered font answers for (default: the bundled Inter)
  --no-default-font                  no fallback face: text no font answers for is not set (to see what a document is missing)
  --cmyk-profile <file.icc>          CMYK working space and PDF/X output intent (an ICC file)
  --engine-from <dir>                resolve the engine (@paged-media/paged) from this directory
  --text                             human-readable output instead of JSON
  -h, --help                         show help
