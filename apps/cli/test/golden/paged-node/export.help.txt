paged-node export <doc>

export through core (pdf, idml, paged) or a plugin exporter (its id or extension); pdf goes through a typed exportPdf command (paged.publish) when one is installed, passing only the options given

options:
  --format <pdf|idml|paged|<exporter>> the output format (default: from -o's extension)
  -o, --out <file>                   the output file (required)
  --pdf-standard <pdf17|pdfx4>       PDF standard (default pdf17)
  --pages <a-b>                      PDF page range (1-based, inclusive)
  --option <key=value>               a PDF option of the typed exporter, typed by its args (repeatable); the rest take their defaults (repeatable)
  --via <command>                    the typed PDF exporter command (default: media.paged.publish.exportPdf, else any *.exportPdf)
  --core                             use core's PDF door even when a typed exporter is installed
  --plugins <a,b>                    load exactly these bundles (package names or paths) instead of discovering them
  --no-plugins                       load no plugin bundles (core objects only)
  --font <file.ttf>                  default font every load lays text out with
  --engine-from <dir>                resolve @paged-media/canvas-wasm from this directory
  --text                             human-readable output instead of JSON
  -h, --help                         show help
