# Binary fixtures in this directory — where they came from

The `.ts` files here are harness code. The binaries are not: every one is
a **copy of something another repo generates**, and none of them recorded
that until the 2026-08 corpus campaign went looking. A reader had no way
to tell a hand-made fixture from a stale copy, which is the whole problem
— the upstream generators are re-runnable, so these silently go out of
date the next time anyone runs one.

Nothing here is generated by the editor. If a fixture looks wrong, fix it
upstream and re-copy; editing it in place makes the two disagree with no
signal.

| File | Canonical source | Refresh |
|---|---|---|
| `sheet-02-formulas.xlsx` | `plugin-sheets/corpus/xlsx-corpus/02-formulas.xlsx` | see below |
| `sheet-07-tables.xlsx` | `plugin-sheets/corpus/xlsx-corpus/07-tables.xlsx` | see below |
| `sheet-09-chart.xlsx` | `plugin-sheets/corpus/xlsx-corpus/09-chart.xlsx` | see below |
| `sheet-14-textstyles.xlsx` | `plugin-sheets/corpus/xlsx-corpus/14-textstyles.xlsx` | see below |
| `doc-memo.docx` | `plugin-doc/docx-conformance/src/lib.rs` → `memo_docx()` | re-emit from that fn |
| `data-people.csv` | authored here (plain CSV, no generator) | edit in place |

All four `.xlsx` are byte-identical to their source as of 2026-08-19,
only renamed with a `sheet-` prefix. To refresh after
`plugin-sheets/corpus/xlsx-corpus/generate.py` runs:

```bash
for n in 02-formulas 07-tables 09-chart 14-textstyles; do
  cp ~/paged/plugins/plugin-sheets/corpus/xlsx-corpus/$n.xlsx \
     apps/canvas/tests/e2e/harness/sheet-$n.xlsx
done
```

## Why these are copies rather than references

The obvious fix — point the specs at the sibling checkout — would put a
plugin repo back on the editor's CI critical path. The platform
deliberately went the other way: the editor consumes every plugin as a
**published npm canary**, and the last `link:` override was removed on
2026-08-18. Re-adding a source-tree dependency to save 60 KB of fixtures
trades a cheap, visible duplication for the expensive kind of coupling
that was just paid off.

So the duplication stays and is documented instead. The cost of it going
stale is now a lookup in this table rather than a mystery.
