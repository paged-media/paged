**AGPL-3.0-only OR PMEL**, like the rest of the repository (ADR PM-0001).

## License of contributions

By contributing you agree to the **Contributor License Agreement**
([`CLA.md`](./CLA.md)), which lets And The Next GmbH distribute your
contribution under **both** the AGPL-3.0 and the commercial PMEL. You retain
copyright to your contribution. A CLA bot will ask you to sign on your first PR.

New source files must carry the standard AGPL-3.0 OR PMEL header — copy it
verbatim from the top of any existing source file in this repo.

## Building & testing

```bash
bun install
bun run typecheck
bun run test
```

Format only the files you touched.
