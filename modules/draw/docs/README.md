# Documentation

What this folder holds.

- [`concept.md`](concept.md): why the plugin exists, what it is for, and what it will never do.
- [`architecture.md`](architecture.md): how it is built. The three TypeScript packages and
  two Rust crates, what activation registers, the main data paths, where data is stored,
  the host doors used, and how it is built and tested.
- [`status.md`](status.md): what ships today, the limits of what ships, and what is not built.
- [`adr/`](adr/README.md): the decision records of this repository, 350–357.

## Decisions in other repositories that bind this one

These records live in other public paged-media repositories. The code here rests on each of
them. The last column says what the decision means for this plugin.

| ADR | Repository | Decision | What it means here |
|---|---|---|---|
| [010](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/010-raw-mutate-gate-capability-enforcement.md) | plugin-sdk | The raw-mutate gate and the capability enforcement line | The plugin writes with raw `document.mutate` operations under `document.write: "scoped"`. Its metadata writes, including the raw `setPluginMetadata` operations it puts inside its own batches, use its own key, `x-paged:media.paged.draw`; `packages/draw-bundle/test/conformance/metadata.spec.ts` asserts that a foreign key is refused. |
| [017](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/017-importer-exporter-door-shape.md) | plugin-sdk | Importer and exporter door shape | `.svg` files are routed to this plugin's importer by extension or MIME type. It receives the file's bytes and inserts paths into the open document; the exporter returns bytes and a file name for the selection (`packages/draw-bundle/src/io/svg.ts`). |
| [305](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/305-doors-always-present.md) | plugin-sdk | Every door is always present; `supports()` reports a missing backend | Optional doors are probed with `host.supports(...)`, each with a stated fallback: without container parts the libraries are not saved, without the importer and exporter doors SVG is not registered, without the binding-provider door there is no Layers provider, without placed-image bytes the trace does nothing, without overlay text the Measure tool keeps showing the line. |
| [307](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/307-contract-as-peer-dependency.md) | plugin-sdk | Bundles take the contract packages as peer dependencies | `@paged-media/plugin-api` and `@paged-media/plugin-sdk` are peer dependencies of `@paged-media/draw`, with the range `>=0.2.29-canary.0` (`packages/draw-bundle/package.json`). |
| [308](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/308-plugin-wasm.md) | plugin-sdk | Plugin wasm is a declared capability, loaded by the bundle, under one size budget | The manifest declares one wasm module, `wasm/trace_js_bg.wasm`, with a ceiling of 2,097,152 bytes. `packages/draw-bundle/src/trace-engine.ts` loads it; `scripts/build-wasm.sh` checks the built size against a separate, larger number. See [ADR 357](adr/357-image-trace-rust-lane.md). |
| [309](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/309-conformance-against-real-engine.md) | plugin-sdk | Conformance runs against the real published engine | `packages/draw-bundle/test/conformance/` drives the bundle through `createHeadlessHost` from `@paged-media/plugin-sdk`. The engine comes from `@paged-media/canvas-wasm`, a devDependency of the bundle package. |
| [310](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/310-one-write-door.md) | plugin-sdk | One write door: `document.mutate`, engine-owned history, failures as outcomes | Every document change goes through `host.document.mutate`. The code tests `outcome.applied` and reports the engine's error. It keeps no undo state: a command takes as many undo steps as it sends mutations. |
| [311](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/311-plugin-state-under-own-id.md) | plugin-sdk | Plugin state lives only under the plugin's own id | State on an element is one envelope under `x-paged:media.paged.draw`. Libraries and recipes are parts in the plugin's own namespace of the container. |
| [312](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/312-panels-as-data.md) | plugin-sdk | Panels cross the boundary as data: a schema plus bindings, no expression language | The Stroke and Fill panels are schemas (`packages/draw-bundle/src/panels/stroke-panel.ts`, `packages/draw-bundle/src/panels/fill-panel.ts`). Sections that depend on the selection are gated by booleans the bundle publishes. The eight panels that list records are React components. |
| [314](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/314-plugin-shape.md) | plugin-sdk | The plugin shape: semantics in Rust behind one wasm module, a logic-free shim, one published package | There is one published package, `@paged-media/draw`, and one wasm module. The TypeScript side is not logic-free: geometry, tool machines and all commands are TypeScript, and Rust holds only the image tracer. See [ADR 350](adr/350-three-typescript-layers.md) and [ADR 357](adr/357-image-trace-rust-lane.md). |
| [315](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/315-isolation-contract.md) | plugin-sdk | The isolation contract: a plugin depends only on the published contract | `scripts/check-contract-imports.mjs` runs before the tests and rejects any static `import … from` or `export … from` other than the two contract packages, this repository's own packages and `react`. One call still goes around the doors: `host.editor.client.send` in `packages/draw-bundle/src/handlers/measure.ts`. |
| [316](https://github.com/paged-media/plugin-sdk/blob/main/docs/adr/316-native-content-and-baking.md) | plugin-sdk | Plugin content is stored as valid native document content; baking is the fallback | Everything the plugin puts on a page is a native page item, with plugin state as metadata on it. Baking here is done by commands, not declared in the manifest; see [ADR 354](adr/354-multi-paint-bakes-to-a-group.md) and [ADR 356](adr/356-live-constructs-are-recipes.md). |
| [004](https://github.com/paged-media/core/blob/main/docs/adr/004-kurbo-geometry-kernel.md) | core | Path geometry kernel: kurbo; booleans stay flo_curves | Outline, offset, simplify, the variable-width outline and all pathfinder operations are engine operations. This repository has no kernel for them; see [ADR 353](adr/353-path-algebra-runs-in-the-engine.md). |
| [005](https://github.com/paged-media/core/blob/main/docs/adr/005-wire-recipe.md) | core | The wire recipe: every operation self-describing and invertible | Every write is one of the engine's typed operations, or a `setElementProperty` on a named property path, and undo is the engine's inverse of each. The bundle learns which operations an engine has from the error an unknown operation returns (`packages/draw-bundle/src/commands/join-average.ts`). |
| [118](https://github.com/paged-media/core/blob/main/docs/adr/118-paged-file-is-a-valid-idml-package.md) | core | A `.paged` file is a ZIP that stays a valid IDML package | The seven libraries and recipes are JSON parts written into the container through `host.parts`; see [ADR 355](adr/355-libraries-in-container-parts.md). |
| [124](https://github.com/paged-media/core/blob/main/docs/adr/124-opacity-masks-native.md) | core | Opacity masks are a native construct; loss is reported on IDML export | Make and Release opacity mask send the engine's `applyOpacityMask` and `releaseOpacityMask` operations (`packages/draw-bundle/src/commands/v58-wire.ts`). The bundle adds only a metadata record of the relation on the masked element (`packages/draw-bundle/src/commands/opacity-mask.ts`). |
| [023](https://github.com/paged-media/editor/blob/main/docs/adr/023-shared-panels-binding-providers.md) | editor | Shared panels: the host owns the panel, plugins provide the values | The bundle has no Layers panel. While its edit context is active it registers as the provider of the host's Layers panel (`packages/draw-bundle/src/binding-provider/`). |
| [024](https://github.com/paged-media/editor/blob/main/docs/adr/024-context-sensitivity-is-a-core-concept.md) | editor | Context-sensitivity is a core concept | The `vectorGraphic` edit context names the three anchor tools and the Stroke panel as what belongs to an entered path (`packages/draw-bundle/src/edit-context.ts`). |
| [208](https://github.com/paged-media/editor/blob/main/docs/adr/208-tools-are-data-plus-gesture-handler.md) | editor | Tools are data plus a gesture handler | Each of the 19 tools in `packages/draw-bundle/src/tools.ts` is a record (id, title, icon, shortcut, group) with a factory for its gesture handler, registered through `contributeTool`. |
